🌱 AgroSphere Frontend

Projet frontend du site AgroSphere, développé avec React, Vite et Tailwind CSS.


---

⚙️ Prérequis

Avant de démarrer, assure-toi d’avoir :
✅ Node.js (version ≥ 18 recommandé, fonctionne aussi avec Node 22)
✅ npm 


---

🛠 Installation

1️⃣ Clone le dépôt :

git clone <URL_DU_DEPOT>
cd agrosphere_front

2️⃣ Installe les dépendances :

npm install


---

🚀 Démarrer en local

Lance le serveur de développement :

npm run dev

Va ensuite sur :

http://localhost:5173


npm install @headlessui/react @heroicons/react

npm install @fortawesome/fontawesome-free
